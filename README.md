# BLITAST GAME

個人開発ゲームのポートフォリオ兼ライブラリサイトです。ゲーム本体は [itch.io](https://blitastxyz.itch.io/) で公開し、このリポジトリは作品一覧・各ゲームの更新履歴・おしらせを掲載します。

**公開 URL:** https://blitast-studio.github.io/blitast-game/

## ローカルで確認

リポジトリのルートで `python -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。作品データやスタイルの編集にはビルド作業は不要です。

ヒーローのThree.jsシーンを変更する場合は、`npm ci` の後に `npm run build:scene` を実行し、生成された `hero-scene.js` もコミットしてください。公開ページは生成済みファイルを直接読み込むため、閲覧時のnpmや外部CDNへの接続は不要です（フォントのみGoogle Fontsから読み込みます）。

## ゲーム・アップデート・おしらせの編集

中身はすべて `featured.js` だけで書きかえられます。ファイル冒頭のコメントに、書き方をまとめています。

### ゲームを追加する

カバー画像を `games/` に置き、`games` 配列に1件足します。上に書いたものが一覧の先頭になります。

```js
{
  title: "新しいゲーム名",
  url: "https://blitastxyz.itch.io/your-game",
  blurb: "一言紹介。こども向けなら「2歳から」など年齢も書くと親切です。",
  cover: "games/your-game.jpg",
  coverAlt: "画像の説明",
  genre: "Action",           // For kids / Action / Platformer / Casual / Puzzle / Arcade / Horror（Platformer は「アクション」と表示。ほかの値は書いたまま表示）
  released: "2026.10.01",    // 任意。おしらせに「新作公開」として出ます
  coverPosition: "50% 20%",  // 任意。一覧のサムネイルで見せたい位置（左右 上下）
  coverLarge: "games/your-game@2x.jpg", // 任意。横1600px以上の大きい画像。大きな表示・高精細な画面で使います
}
```

スマホ（タッチ）では遊べないゲームには `mobile: false` を付けます。一覧に「パソコン向け」と表示され、「スマホ対応 ○作品」の数から自動で外れます。

`featured: true` はおすすめ枠の1本に、`spotlight: true` は本格開発中の特別枠の1本に設定します。

説明文（`blurb`）に `|` を入れると、そこが改行してよい区切りになります（`|` は表示されません）。ひらがなの多い文は「みぎはしで|つぎの|ページへ。」のように区切っておくと、どのブラウザでもことばの途中で改行されません。

### 編集後に「読み込めませんでした」「書きまちがいがあります」と出たら

`featured.js` のどこかでカンマ（`,`）や引用符（`"`）がぬけているか多すぎます。ローカルで開くと、ページに何行目あたりかが表示されます（ブラウザの開発者ツールの Console にも出ます）。直して保存し、再読み込みしてください。

### アップデートを書く

同じゲームの `updates` 配列の**先頭**に追加します。

```js
updates: [
  {
    date: "2026.10.01",
    text: "v0.1.8 夜明けモード\n変わったこと1\n変わったこと2",
  },
]
```

- 1行目が見出しです。`v0.1.8` のような番号は自動でバッジになります。1行目が番号だけのときは、2行目の最初の一文が見出しになります。
- 2行目以降が「何が変わった？」の中身です（1行＝1項目）。
- 書いたアップデートは「おしらせ」の時系列と、そのゲームの「更新の記録」の両方に自動で表示されます。14日以内のものには NEW が付き、最新のものはヒーローの「最新アップデート」にも出ます。

### サイトからのおしらせを書く

トップレベルの `news` 配列の先頭に追加します。

```js
news: [
  { date: "2026.10.01", title: "見出し", text: "本文1行目\n本文2行目", url: "https://…（無くてもOK）" },
]
```

### 特定のゲームへのリンク

ページのアドレスの最後に `#game/<itch.ioアドレスの最後の部分>` を付けると、そのゲームの詳細が開きます（例: `…/blitast-game/#game/catwalk`）。SNSで特定のゲームを紹介するときに使えます。

## サイトの構成

- `index.html` — ページ構造（ヒーロー、ゲーム一覧、おしらせ、はじめての方へ、フッター）
- `styles.css` — デザインとレスポンシブ表示
- `site.js` — ゲーム一覧・絞り込み・ゲーム詳細・おしらせの時系列・BGM・共有
- `featured.js` — 作品データとおしらせ
- `src/hero-scene.js` — Three.jsシーンの編集用ソース。動きを減らす設定を尊重し、画面外では停止します
- `hero-scene.js` — 公開用にまとめたシーンのコード（`npm run build:scene` で生成）
- `og.png` — SNSで共有したときのプレビュー画像

ヒーローの3Dシーンは、`data-hero-avoid` を付けた要素（見出しのかたまり等）の位置を読み取り、文字に重ならないように惑星系を配置します。ヒーローの文字レイアウトを変えたときも、シーンの再ビルドは不要です。

`main` ブランチのルートを GitHub Pages が公開しています。変更を `main` に反映すると、同じ公開 URL の内容が更新されます。
